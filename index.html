Install on iPhone

Open this page in Safari → Share → Add to Home Screen. Launch it from the icon for full‑screen mode and notifications.

Pins

Red ring = place to visit. Green ring = visited. Give each place a type (castle, beach, food, nature, museum, pub, stay) and the icon changes; turn this off in Settings for plain pins. Long‑press the map or use the search box to add a place. Swipe up the Places bar for a scrollable list — tap a row to fly to it.

Import your Google Maps places

  1. Go to takeout.google.com → Deselect all → tick Maps (your places) and Saved → Next → Create export.
  2. Download the zip on your iPhone, open it in Files (tap to unzip).
  3. Menu → Import from Google Maps → choose Saved Places.json and the list .csv files.

Google's list CSVs usually contain names but no coordinates; the app looks those up by name via OpenStreetMap. Check anything that landed in the wrong place and drag it (Edit → coordinates) if needed.

Background alerts via Reminders (one‑time setup)

In the Shortcuts app create a shortcut named exactly Trip Pins Reminders:

  1. Receive Text input from Share Sheet / Shortcut input.
  2. Split Text (Shortcut Input) by New Lines.
  3. Repeat with Each item:
    1. Split Text (Repeat Item) by Custom “|”.
    2. Get Item from List → First Item (name). Get Item from List → Item at index 2 (latitude), index 3 (longitude), index 4 (radius m), index 5 (note).
    3. Add New Reminder: title = “You're near [name] — it's on your list!”, List = Places nearby, Alert = Location, Arriving, location = the latitude,longitude text. Notes = note.

Create a second shortcut named Trip Pins Clear: Find Reminders where List is Places nearby → Remove Reminders.

If your iOS version's Add New Reminder action doesn't accept a radius, open the Reminders app once after creating them and drag the circle wider on each — or use Copy list and add them by hand.

Updates

When new files are uploaded to your site, the app fetches them automatically the next time it's opened online and reloads itself. Your places are unaffected.
